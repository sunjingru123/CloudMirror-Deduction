# 项目说明

## 1. 项目概况

- **项目名称**：云镜推演
- **英文名称**：CloudMirror Deduction
- **项目地址**：<https://github.com/sunjingru123/CloudMirror-Deduction>
- **当前阶段**：项目骨架初始化

> 本文档用于说明项目定位与目录约定。截至目前，仓库中尚未包含任何已实现的业务功能，请勿将规划内容理解为已交付能力。

## 2. 目标与技术选型

项目采用前后端分离架构：

| 层次 | 技术 | 状态 |
| --- | --- | --- |
| 后端框架 | FastAPI | 规划中 |
| 后端运行时 | Python 3.11+ | 规划中 |
| 前端框架 | Vue 3 | 规划中 |
| 前端构建 | Vite | 规划中 |
| 包管理 | pip / npm | 规划中 |

## 3. 目录结构说明

| 目录 | 用途 |
| --- | --- |
| `frontend/` | 前端应用（Vue 3 + Vite），尚未初始化 |
| `backend/` | 后端服务（FastAPI），尚未初始化 |
| `docs/` | 项目文档 |
| `data/` | 数据文件目录，大文件不入库 |
| `screenshots/` | 界面截图与演示图片 |

## 4. 开发约定

1. 使用 `main` 分支作为主干，功能开发建议使用独立分支后合并。
2. 遵循 `.gitignore` 约定，不提交 `.env`、密钥、虚拟环境、`node_modules`、构建产物。
3. 新增环境变量时，同步更新 `.env.example`（仅示例值，不含真实密钥）。
4. 提交信息使用简洁、明确的中文或英文描述。
